# Nyxen

A Windows companion for your games: mods from four sites at once, Minecraft
with whatever launcher you already use, RetroArch achievements, and friends.

**Download:** https://github.com/Kerioxsx/nyxen/releases/latest

**Site:** https://Kerioxsx.github.io/nyxen/

Free, installs without administrator rights, and needs no account to be
useful. Windows 10 and 11 only.

The installer is not code-signed, so SmartScreen will warn you the first
time. The SHA-256 is published beside the download and in `sha256.txt`.
