What is in it

Everything it does

Every item here is a feature that exists in the build on this page. Nothing on this list is planned, coming soon, or a mock-up.

Mods

Four mod sites, one search box

Thunderstore, Modrinth, GameBanana and the Steam Workshop, searched together and interleaved so one site's catalogue does not bury the other's.

  • Tick several mods, install them in one go
  • Checks each build against your loader before downloading
  • Turn a mod off without deleting it
  • Share a mod list with friends; their copy fetches the files
  • Brings Workshop items into games that do not read that folder
Minecraft

Whatever launcher you already use

Reads the official launcher, Prism, MultiMC, the Modrinth app, CurseForge, ATLauncher, GDLauncher and XMCL, wherever they already are. Nothing extra to install.

  • Mods, shaders, resource packs and data packs
  • A brand new instance with no mods at all
  • Export a .mrpack to send someone
  • See what is installed, per instance, and toggle it
  • Server list with live pings; recommendations for your pack
Minecraft

Your skin, in 3D

A real model you turn with the mouse, drawn without any 3D library so it works offline. Look up any player's skin by name, which needs no account at all, and wear one if you sign in.

Retro

RetroArch and RetroAchievements

Finds RetroArch by itself and identifies your ROMs by hash against 141 systems. No key, no account, and it works offline after the first lookup.

  • What you are playing, its platform and its player count
  • Cheats, from RetroArch's folder or libretro's 28,000 files
  • Your achievement progress, using the login RetroArch stores
  • A shelf of box art for everything it recognised
Achievements

Your collection, and what is close

Everything you have earned across your library, sorted by how near you are to finishing it.

  • Rarest achievements, and rarity for the game you are in
  • Nearly there, and the graveyard of what you abandoned
  • Per-game completion and a running total
Friends

Friends, with no company in the middle

Profiles, direct messages, calls and screen sharing between your own installs. The server is one small file you can run yourself.

  • Profile with what you are playing and its art
  • Groups, challenges and a leaderboard
  • Join by a link, not an account on someone's platform
Assistant

An assistant that can see the game

Ask about the game you are in. It can read the screen when you ask it to, keep notes between sessions, and coach you through a run.

Toolkit

The small things, in the same window

  • Custom crosshair overlay
  • Screenshots, with a gallery
  • Notes that stay with the game
  • Audio mixer and media controls
  • Calculator, colour picker, randomizer
  • Session timers and input statistics
Look

26 themes, six of them alive

Inside the app the backgrounds move — drifting scenes behind the interface. All of it stops when the window is not in front, so it costs nothing while you are in a game.

Getting started

No surprises

Before you install

The awkward parts, up front rather than afterwards.

Windows only Windows 10 and 11. There is no macOS or Linux build.
Not code-signed SmartScreen will warn you the first time, as it does for any installer without a paid certificate. The SHA-256 below lets you check the file instead.
No account to use it Mods, Minecraft, retro, achievements and the toolkit all work with nothing signed in. An account is only for friends and messages.
Some features use logins you already have A Minecraft skin change needs a Microsoft sign-in. Retro progress reads the RetroAchievements login RetroArch stores, and only after you switch that on.
The assistant needs a key, or a local model Chat and the screen assistant use whichever provider you configure. Leave it alone and the rest of the app is unaffected.
Nothing is uploaded Library, screenshots, notes and statistics stay on your PC. Mod downloads come straight from the mod sites.
Uninstalls cleanly Per-user install, an ordinary Add / Remove Programs entry, and your settings survive updates.
